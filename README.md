# Appointment Organizer

A simple and clean SwiftUI application for organizing appointments and reminders.

## Features
- Add appointments
- Select date and time
- Delete appointments
- Dark mode UI
- Simple and user-friendly design

## Built With
- Swift
- SwiftUI
